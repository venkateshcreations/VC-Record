Under The Hood

Modern Desktop Architecture

Engineered for rock-solid reliability by combining native Windows Desktop Duplication with modern web technologies.

01 // VIDEO ENGINE

Hardware-Accelerated FFmpeg

Bundled static FFmpeg directly leverages NVIDIA NVENC (h264_nvenc), Intel Quick Sync (h264_qsv), and AMD AMF (h264_amf) with automatic CPU fallback to libx264.

02 // AUDIO MIXING

Web Audio API & WASAPI

Connects your live microphone audio stream and Windows system desktop sound loopback directly into an AudioContext destination node, ensuring zero audio-video drift.

03 // DESKTOP DUPLICATION

Electron 34 Runtime Security

Complete context isolation with atomic local filesystem writes. Zero network traffic, zero third-party telemetry, packaged cleanly via Electron Builder for Windows.
